## About

I'm a developer from Indonesia who cares about building software that **stays useful six months from now**, not just on demo day. I work across the stack — backend systems, web frontends, and mobile apps — with a bias toward **pragmatic, maintainable solutions** over clever hacks.

Currently focused on:
- Multi-tenant SaaS architectures (Express + PostgreSQL + React)
- AI-integrated products (RAG systems, LLM workflows)
- Mobile development with Flutter for cross-platform delivery

I prefer **JavaScript** in production. My day-to-day: shipping features, reviewing my own diffs before committing, and pushing back on designs that won't survive contact with reality.
